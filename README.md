# 网文写作规则（去 AI 味 · 量化版）

> 一套**先量、再改、改完再量**的中文网文写作规则。
> 不靠"感觉像不像人写的"，靠可复现的数字 + 可执行的改稿动作。

- 适用：中文网络小说（男频为主，女频同样可用）
- 不适用：纯文学短篇的审美判断、翻译腔的文学转译
- 配套脚本：`tools/style-stat.js`（Node.js，无依赖）

---

## 这套规则解决什么问题

AI 写的稿子通常不是"词不对"，是**句子结构不对**：

- 一句里塞三四个小动作，句句都在推镜头，信息量却是零
- 分句残缺，读者一口气被打断七八次
- 段落长短一样，读起来像提纲
- 情绪靠形容词，不靠事实

所以规则的核心不是"禁用词表"，而是三件事：

1. **量**：把句子拆成分句，看每个分句多长、每句几个分句
2. **判**：长句是"长在层次"还是"长在动作排队"
3. **改**：按固定顺序做手术，改完再量

## 一、先量，再谈别的

```bash
# 单章（可一次量多个文件）
node tools/style-stat.js 稿子.md

# 样本库分段（每章均值 + 段内比率）
node tools/style-stat.js --corpus 参考书.txt --bands 1-20,21-100,101-300,301-500
```

脚本输出：字数、句长中位、长句/短句占比、每分句字数、每句分句数、
单句成段占比、含对白段占比、动词密度、关联词密度、"的"密度、
A 级词命中、段首"他"、半角引号。

**先说清楚一件事：刻度不是通用的。**

同一套算法量两本成绩都不错的书，结果差得很远：

| 指标 | 书 A（说书腔·短分句） | 书 B（史诗腔·长分句） |
|---|---|---|
| 句长中位 | 17–19 | 20–22 |
| 每分句字数 | 8.5–9 | 10.5–11 |
| ≥20 字句占比 | 37–48% | 51–57% |
| "的"密度 | 32–36 | 45–54 |

**所以永远先量你自己的参考书**，再用它的数当验收线。拿别人的表格硬套，只会把稿子改成四不像。

## 二、六步流程（照顺序做）

1. **定体裁和目标读者。** 悬疑和爽文的"长句"不是一种长句。这一步错了，后面全错。
2. **分段抽样读。** 按 1–20、21–100、101–300、301–500、501–700、701–1000 分六段，**每段抽 7–8 章整章读**。只读开头就动笔，必然照抄开局的写法去写全书。
3. **量刻度。** 跑 `--corpus`，把每段的字数、句长、分句、对白占比做成表。
4. **解剖句子。** 每段挑十句最长的，标出它是"长在层次"还是"长在动作排队"。
5. **写或改。** 按第四节起的手册条目。
6. **自检。** 先跑脚本，再人读一遍。**脚本过、人读不顺，以人读为准；人读顺、脚本不过，说明样本读得不够。**

## 三、两种长句（这一条最值钱）

同样二十个字一句，内部可以完全不同：

| | 分句数 | 每分句字数 | 读感 |
|---|---|---|---|
| 真人稿 | 2.0–2.2 | 9–11 | 一句说完一件事，句内有因果、有判断 |
| AI 稿 | 2.8–3.2 | 5–7 | 一句里塞四五个小动作，句句都在推镜头 |

**真人的长句，长在层次：**

> 饶是他如今已是古稀之年，却也不禁心中暗自得意。
> 五十多年来，他从一无所有到如今官拜太师、权倾天下，这其中种种，足以写成一本几百万字的长篇小说。

让步、提示、时间跨度、评价——人只出现一次，剩下全是判断和信息。

**AI 的长句，长在动作排队：**

> 片子插在灯箱上，白得刺眼，医生看了一会儿，伸手把灯关了。

四五个动词排成一列，没有一句在给新东西。

### 判断标准（四选一，四样全无就是水）

每写一个长句，问：除了动作，这句话里有没有下面任意一样？

1. **一个数**（几万、三十年、十之八九）
2. **一个判断**（"这城不大，够一个穷人活，也够一个穷人死"）
3. **一个对比或让步**（却、饶是、至于、反倒）
4. **一条规矩或事实**（每亩三升、房租三百五、医保报三成）

### 手术方法

- **分句少于 7 字**：补齐主语或宾语，或并进上一分句的定语里
- **一句超过 3 个分句**：拆成两句，或把其中两个分句压成定语
- **连续两句都短于 8 字**：前一句的句号改逗号
- **关联词低于 40/千字**：在转折、递进、因果处补"却、便、则、至于"

## 四、十个维度怎么写

1. **主角个性**：不写"他聪明"，写他做了什么。每个决定前给一句"算账话"；每个计划拆成 2–4 个可数动作；先写"心动"再写"忍"。
2. **开篇切入**：第一句只给"人＋动作"，≤25 字。不写天气、不写心情、不重设场景；换场景只给半行地点标签。
3. **反派配角**：给一件很私人的小欲望；说人话（杀完人抱怨"这差事真累"）；输了有风度；顺手交代设定。
4. **危机推进**：三层压力（命、规则、强敌）同时压；**先让别人付账**；倒计时摆明；失败要复盘。
5. **环境描写**：2–3 句，一句一物，只给形状、光、味道；写完立刻接人物的动作或判断。绝不单独写景。
6. **期待感**：章末一句独立成段的短句，三选一——新信息、反差、下一步。钩子必须能一句话说完。
7. **趣味与粘性**：信息差、捡漏、装、反转、反差、小动作，六招轮着用。章末给"下一步"，不给"谜"。
8. **互动**：四套语气——对上位者诉苦讨价，对平辈敬称半真半假，对下属短命令，对敌人短冷。
9. **短句**：只占 7–10%，只放在情绪顶点、动作瞬间、转折、惊骇。其余全用逗号连缀。
10. **水字数**：水在读者爱看的地方——谈判写三轮、复盘推理、设定讲解、生活共鸣、让读者算账；**打斗和纯写景一笔带过**。

## 五、AI 腔清单

### A 级（出现即改）

涌上心头、心头一紧、心中一暖、心中一沉、勾起一抹、弧度（写表情）、深邃、凝滞、
不易察觉、几不可察、只有他知道、声音不大，却。

### B 级（不绝对禁，但不能扎堆）

顿了顿、一抹、一丝、仿佛、像是、某种、莫名、不知为何、终于、不禁、
缓缓、淡淡、沉默、那一刻、闪过、泛起、说穿了、说白了。

> 判定标准不是"有没有"，而是**密度**：B 级合计超过 60/千字就要削。

### C 级（句法模板，比词更严重，脚本查不出，必须人工过）

1. **不是 A，是 B** ／ 不是 A，也不是 B，而是 C（排除法）
2. **不懂 A。只懂 B** ／ 不知道 A，只知道 B（对偶收尾）
3. **他愣住了。** 单独成段、后面不接东西
4. **那一刻** 当抒情引子
5. **段首"他"**（每章应≈0，改用名字、物件、时间、对话起头）
6. **说完，他自己也愣了**（叙述者替人物点评）
7. **只有他知道，有什么东西不一样了**（替读者点破）
8. 破折号揭晓（"他找到了一条路——一条……"）
9. 冒号列举（"原因有三个："）
10. 半角引号（中文正文一律全角）

**注意：脚本只查 A/B 级词表，C 级一个都查不到。写完必须自己搜一遍。**

## 六、改稿手术顺序

1. **删水**：删掉所有"只记录、不交货"的动作句和纯写景。一句问一次："删了，读者少知道什么？"答不出，就删。
2. **合句**：两个相邻短句用一个逗号接起来。
3. **补分句**：把每个分句补到 7–9 字，主谓宾齐。
4. **加层次**：每句塞进"数／判断／对比／规矩"里的一样。
5. **调配比**：对白段拉到 25%–32%（开篇章不低于 20%）。
6. **留短句**：只在四个位置留，其余全连缀。
7. **跑脚本**，不达标回到第 2 步。
8. **人读一遍**，读着不顺，回到第 1 步。

## 七、分段精读：一本书在不同段落是几种写法

这条最容易被跳过，也最容易被证明有用。

以一本七百多章的书为例，全章统计（不是抽样）：

| 段 | 1–20 | 21–100 | 101–300 | 301–500 | 501–700 | 701–731 |
|---|---|---|---|---|---|---|
| 章首均长（字） | 29.6 | 26.6 | 18.4 | 15.1 | 17.3 | 19.9 |
| 短标签式开头占比 | 5% | 20% | 39% | 54% | 45% | 26% |
| 章末句长中位 | 21 | 17 | 16 | 17 | 16 | 24 |

结论：

- **开局**用长句起手、长句收尾，几乎不用地名标签
- **中段**改成"地名标签起手 + 短判断收尾"，一章切几个板块、视角下放给配角
- **结尾**又回到长句，并且常把第一章的戏重演一遍

也就是说：**照抄中后段的章法去写第一章，必翻车。**

操作上：

- 每段整章读 7–8 章，不要只读前二十章
- 记下每段的"章首第一句"和"章末最后一句"，做成表
- 长句解剖每段挑十句，标"层次"还是"动作排队"
- 注意视角：什么时候从主角下放给配角，什么时候切成多线

## 八、真人语感：把功能字补回去

AI 稿最明显的特征不是用了什么词，而是**少了什么字**。

真人写字会随手带上这些：

**了** —— 时态落地。AI 稿常常一个"了"都没有，句子悬在半空。
**便** —— 等于"就"，说书腔的骨头。
**这样 / 那样** —— 口语的指示词，用来替代精确描述。
**似的 / 一样** —— 比喻的软化。
**倒是 / 倒也 / 罢了 / 什么的 / 之类的** —— 语气的余量。
**才 / 就 / 也 / 都 / 还 / 又 / 只** —— 中文的黏合剂，缺了句子就硬。

对照：

| AI 版 | 真人版 |
|---|---|
| 他坐下，等天亮。 | 他坐下来，便等着天亮。 |
| 那兵看见了他。 | 那兵竟然看见了他，眼睛睁得这样大。 |
| 他碰了一下。 | 他伸手碰了碰，像这样轻轻一按。 |
| 手是空的。 | 手却是空的，什么也抓不住。 |

**量化上的连带效果**：这些字大半是关联词表里的（便、也、都、就、才、还、又、只），补回去，关联词密度自然上到 40–50，句子之间也就有了逻辑。

**但别硬塞**：一段里"便"超过两回就腻，"这样"连着出现就啰嗦。功能字是盐，不是米。

## 九、数字的纪律

数是最容易变成 AI 味的东西：一段里堆五六个数字，读着像报表。

规则：

1. **数字只用来给读者算账**（代价、期限、距离、价格），不用来堆气势。
2. **一段里最多一个数**。第二个数出现时，前一个多半该删。
3. **能模糊就模糊**：数不清、好些、半袋、一大把、不知多少回。
4. **精确数要能被用上**。读者算不出结果的精确数，就是装饰。
5. **不要用数字强调重要性**："他有三条路""原因有两个""这是第三点"——这类编号是提纲，不是小说。

对照：

| 数字化写法 | 改后 |
|---|---|
| 他记得的事一共十一件。 | 他记得的事已经不多了。 |
| 他背上背着十七份死。 | 他背上的份数，他自己也数不清了。 |
| 三十七年前的那场仗。 | 那场仗打得很久了，久到没人记得为什么打。 |

## 十、原创边界：只仿机制，不仿皮

想学某一本的结构或外挂，可以，但要划清界线。

**可以借的（机制层）**

1. 主角不在世界之内（无实体、不可见、碰不到东西）
2. 只有极少数人能感知他（比如将死的人）
3. 被他碰到／看见的人会得到一样东西
4. 他不能直接干涉世界，只能经这些人落手
5. 这条通道有代价，用一次少一次

**不能借的（内容层）**

专有名词、地名、人物名、势力名、桥段顺序、核心道具、标志性台词。

**自检一句**：把借来的东西抽成一句话之后，如果还剩下任何专有名词，那就是在抄，不是在学习。

## 十一、验收清单

打印贴墙，每章过一遍。

**硬指标（脚本）**

- [ ] 章字数落在本书区间
- [ ] 句长中位、分句字数、分句数，落在本书样本的区间内
- [ ] ≥20 字句、≤6 字句比例符合样本
- [ ] 段首"他"≈0
- [ ] A 级词 0；B 级合计 <60/千字
- [ ] 半角引号 0

**硬指标（人工，脚本查不到）**

- [ ] C 级句法模板 0（尤其"不是 A，是 B"）
- [ ] 每句长句含"数／判断／对比／规矩"之一
- [ ] 数字没有扎堆，没有用编号讲道理
- [ ] 功能字（了／便／这样／那样／似的）自然存在，不硬塞
- [ ] 章首第一句是人＋动作，≤25 字
- [ ] 章末一句独立成段的短句
- [ ] 主角有一个"算账句"
- [ ] 反派有一个"私人小欲望"
- [ ] 有一处"别人先付账"
- [ ] 写景不超过三处，每处不超过两句，景后接人
- [ ] 删过一遍"删了也不影响"的句子
- [ ] 最后人读一遍，读着不顺就回炉

## 十二、一句话

> 真人把话**说圆**（分句齐全、有层次），把气**顿住**（短句只在要点），
> 把紧张**转嫁**（别人的命先付账），把读者**骗到下一章**（一句钩子）。
>
> AI 把话**切碎**（分句残、动作多），把气**撒平**（句句一样长），
> 把紧张**自己扛**（只写主角心理），把读者**留在原地**（章末抒情）。

## 附：脚本说明

`tools/style-stat.js` 是一个零依赖的 Node.js 脚本。

| 列 | 含义 | 参考用法 |
|---|---|---|
| `han` / `nonWS` | 汉字数 / 非空白字数 | 对比你的样本 |
| `sentMed` `p25` `p75` `p90` | 句长中位与分位 | 对比样本 |
| `long20` | ≥20 字句占比 | 对比样本 |
| `short6` | ≤6 字句占比 | 一般 <10% |
| `clauseAvg` | 每分句字数 | 对比样本 |
| `clausePerSent` | 每句分句数 | 对比样本 |
| `onePara` | 单句成段占比 | 对比样本 |
| `dlgPara` | 含对白段占比 | 25%–32% |
| `verb` `link` `de` | 动词/关联词/"的"密度 | 只作对比 |
| `taStart` | 段首"他"的段数 | ≈0 |
| `hitA` `hitB` | A/B 级词命中 | A 级须为 0 |

**已知偏差**

- 句子切分在引号内也会断，"他说。"这种尾巴会算成一个短句
- 少于 6 字的段落不计入，这是为了和样本同一把尺子
- 动词、关联词是固定词表，只用于对比，不能当绝对标准
- 对白多的章节，句长中位天然偏低，要分列看
